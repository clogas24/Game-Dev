# Growth Spurt — Project 4 (CSCI 5999B, theme: "Big")

A 3D size-shifting puzzle platformer made in Unity 6 (6000.6.3f1, URP).
You are a lab test subject who can switch between **Small**, **Normal** and **Big**
to escape the facility. Each size solves one problem and creates another.

## Layout
- `GrowthSpurt/` — the Unity project
- `docs/` — High Concept Document, Game Script, playtest notes

## Builds
Windows, macOS and Linux builds are uploaded to Box (not committed to git).

## Playtest iterations
Each playtest round is tagged in git (`p4-playtest1`, `p4-playtest2`, ...).
The changes made after each round, and why, are described in the Game Script.
